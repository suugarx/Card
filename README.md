# บัญชีร้านการ์ด (Vercel + Supabase)

เว็บบันทึกรายรับ รายจ่าย ทุนสต็อก และบัญชีเงินของร้านการ์ด แต่ละอีเมลที่สมัครเห็นเฉพาะข้อมูลของตัวเอง

ไฟล์ในโฟลเดอร์
- `index.html` หน้าเว็บทั้งหมด (ไม่มีขั้นตอน build)
- `config.js` ใส่ค่าเชื่อมต่อ Supabase
- `schema.sql` สร้างตารางและกฎให้แต่ละคนเห็นเฉพาะข้อมูลตัวเอง

## 1. ตั้งค่า Supabase (ฟรี)

1. สมัครที่ supabase.com แล้วกด New project
2. ไปที่ SQL Editor > New query วางเนื้อหาไฟล์ `schema.sql` แล้วกด Run
3. ไปที่ Project Settings > API คัดลอก Project URL กับ anon public key
4. เปิดไฟล์ `config.js` แล้วแทนที่ค่า `YOUR-PROJECT` และ `YOUR-ANON-KEY`

อีเมลยืนยัน: ค่าเริ่มต้นของ Supabase ให้คนสมัครกดลิงก์ยืนยันในอีเมลก่อนเข้าใช้ ถ้าไม่อยากให้ยืนยัน ให้ไปที่ Authentication > Sign In / Providers > Email แล้วปิด Confirm email (ถ้าเปิดไว้ ส่งอีเมลได้จำกัดจำนวนต่อชั่วโมง)

## 2. อัปขึ้น Vercel

วิธีที่ 1: ใช้ Vercel CLI
```
npm i -g vercel
cd card-shop-vercel
vercel --prod
```
ตอนถามให้ตอบว่าไม่มี build command และให้ Output Directory เป็น `.`

วิธีที่ 2: ใช้ GitHub
1. อัปโฟลเดอร์นี้ขึ้น GitHub repo
2. ที่ vercel.com กด Add New > Project เลือก repo นั้น
3. Framework Preset เลือก Other ปล่อยช่อง build ว่างไว้ แล้วกด Deploy

## 3. ตั้งค่าหลังได้ลิงก์

- Supabase > Authentication > URL Configuration ใส่ Site URL เป็นลิงก์ของ Vercel (ใช้กับลิงก์ในอีเมลยืนยัน)
- โดเมนของตัวเอง: Vercel > Settings > Domains แล้วทำตามที่ Vercel บอก

## วิธีใช้กับเจ้าของร้านสองคน

ให้แต่ละคนเปิดลิงก์เดียวกันแล้วกด "สมัครใช้งาน" ด้วยอีเมลของตัวเอง คนที่ 1 เห็นเฉพาะข้อมูลคนที่ 1 คนที่ 2 เห็นเฉพาะข้อมูลคนที่ 2 ไม่ปนกัน

## ข้อควรรู้

- ระบบโหลดรายการย้อนหลังสูงสุด 1,000 วัน (ประมาณ 2 ปีครึ่ง) ถ้าใช้นานกว่านั้น วันที่เก่าสุดจะไม่ขึ้นในหน้า ให้ดาวน์โหลด CSV เก็บไว้
- หน้าเว็บเช็คสลิปกับธนาคารไม่ได้ มีเพียงเตือนเมื่อเลขอ้างอิงซ้ำกับที่เคยบันทึก
- ข้อมูลอยู่ใน Supabase ของคุณเอง คนอื่นดูไม่ได้ถ้าไม่มีสิทธิ์เข้าโปรเจกต์ Supabase

## อัปเดต: ระบบ Lot
- ไม่ต้องแก้ SQL เพิ่ม ข้อมูลเดิมยังอยู่
- ตอนบันทึก "ซื้อสต็อกการ์ด" ระบบจะให้ตั้งชื่อ lot ใหม่ แล้วเลือก lot นั้นตอนบันทึกรายรับ/ค่าใช้จ่ายที่เกี่ยวข้อง
- แท็บ Lot แสดงกำไรและ % คืนทุนของแต่ละ lot ส่วนรายการเก่าให้เปิดแถวในแท็บ "รายการ" เพื่อจัดเข้า lot

## อัปเดต: ขายเป็นซอง + ติดตั้งเป็นแอป
- กด "ซื้อ box ใหม่" ใส่ชื่อ ราคา และจำนวนซอง ระบบคิดทุนต่อซองให้
- กด "ขายซอง" เลือกจำนวน ราคาซองละ (ถ้าขายราคาพิเศษ แก้ "ราคารวม") และช่องทางขาย
- กำไรเดือน = ขายได้ − ทุนของซองที่ขาย − ค่าใช้จ่ายอื่น วันที่ซื้อ box จะไม่ขึ้นว่าขาดทุน เพราะเงินกลายเป็นของในร้าน
- lot เก่าที่ยังไม่มีจำนวนซอง: เปิด "ดูรายการ" ใน lot นั้น แล้วใส่ "จำนวนซองทั้งหมด"
- ติดตั้งเป็นแอป: Android/Chrome กดปุ่ม "ติดตั้งแอป" ในหน้าแรก / iPhone เปิดใน Safari กดแชร์ → "เพิ่มไปยังหน้าจอโฮม"
- อัปโหลดทุกไฟล์ในโฟลเดอร์ (รวม sw.js, manifest.webmanifest และโฟลเดอร์ icons)

## อัปเดต: lot ใส่ของได้หลายอย่าง
- "ซื้อของเข้า" ใส่ยอดที่จ่ายทั้งหมด แล้วเพิ่มของที่ได้มาทีละอย่าง (ชื่อ จำนวน หน่วย และทุนถ้ารู้)
- ของที่ไม่ได้ใส่ทุน ระบบเฉลี่ยเงินที่เหลือตามจำนวนชิ้น
- ตอนขาย เลือกว่าขายของชิ้นไหนใน lot
- แก้ไขของใน lot ได้ที่ "ดูรายการ" → "แก้ไขของใน lot"
